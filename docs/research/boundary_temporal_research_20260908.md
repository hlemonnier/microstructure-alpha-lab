# Temporal information beyond finite quote windows

This note was written while the corrected transformer screen remained sealed and before the prequential and fading-memory market runs. It adds no model trial or promotion. The same exact five-second target, decision rows and development-date exposure remain in force.

The registered [online adaptation](boundary_prequential_definition_20260908.json) changes the fitted prediction rule after new outcomes become available. The registered [fading-memory experiment](boundary_fading_memory_definition_20260908.json) changes the observation representation: a continuous state is updated every second before any supervised subsampling. These address different possible failures of a fixed snapshot classifier. Neither is reinforcement learning.

The existing research already includes level-two signature areas, multi-scale lag features, long activity averages, finite event windows, temporal convolutions and sequence MLPs. Merely renaming any of these would not create a new hypothesis. The contractive reservoir adds a persistent nonlinear state with matched instantaneous and exponential-memory controls. Its input projection and recurrent matrix are fixed; only its downstream classifier is trained.

Learned recurrence is a distinct subsequent candidate. [Cho et al., section 2.3](https://aclanthology.org/D14-1179.pdf) introduce learned reset and update gates, allowing the retention rule to depend on both the incoming observation and previous state. A market test could therefore compare fixed fading memory with a trained GRU under the same observation clock. Their translation results provide no quantitative evidence for this market task. This note does not register a GRU fit, a training budget or an expected gain.

Continuous-time models require care at the observation boundary. [Morrill et al.](https://arxiv.org/abs/2106.11028) distinguish everywhere-online, discretely-online and offline interpolation. Their rectilinear construction supports online prediction with missing data; backward-difference Hermite interpolation is another option under the stated observation conditions. A natural cubic spline fitted to a complete session can let later observations alter earlier controls. If a neural CDE is tested here, interpolation, missing observations and prediction timestamps must pass future-prefix tests independently of the differential-equation solver. Their medical benchmark results are architectural motivation, not a market comparison.

[Chevyrev and Kormilitzin](https://arxiv.org/abs/1603.03788) give Chen's concatenation identity, signed-area interpretations and the assumptions behind signature representations. Our modeling implication is narrower than a claim of sufficient statistics: a finite truncation need not retain every predictive detail, and invariance to time reparametrization can discard arrival-speed information that matters for a fixed five-second target. A future signature extension would need a concrete missing interaction, such as additional cross-venue path ordering, and a matched lower-order control. The already tested level-two area features alone are not a new discovery.

The next execution order remains fixed: finish and reveal the corrected transformer family; complete the synthetic runtime checks; freeze and run delayed supervised adaptation; then freeze and run the three memory mechanisms. Any promising whole procedure still requires independent dates. Additional architectures should be selected for an identifiable information or learning limitation, not for the novelty of their names.
