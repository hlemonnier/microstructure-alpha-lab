# Pretrained transformer query causality

The first TabICLv2 market comparison stopped before any assessment scores were inspected. Seven model procedures completed on June 3; the eighth failed the registered changed-future-query check. All initial artifacts remain under `results/boundary_tabicl_screen_20260908`. No date was completed and no accuracy summary was produced.

The [pinned upstream preprocessing implementation](https://github.com/soda-inria/tabicl/blob/0dbff3ec8fc68c123c87af77b0ea8b25cd2d23f3/src/tabicl/_sklearn/preprocessing.py#L751) catches a power-transform exception and clips the entire query batch to fitted training bounds. An extreme later row can therefore change an otherwise valid extrapolation in an earlier row. This is a preprocessing dependency, despite the transformer's attention using only training examples as context.

The preserved June 3 full-morning combined checkpoint reproduces a maximum earlier-probability change of 0.000034859449060065106 for BTCUSDT after later rows are perturbed. ETHUSDT has zero earlier-probability change in the same diagnostic. The original allowed tolerance was 0.000002.

The local adapter isolates failing rows recursively. It retains the normal transform for every successful row and uses the existing training-bound fallback only for an individually failing row. This reproduces the upstream singleton-query semantics while making batch partitioning irrelevant. It changes no trained statistic, power exponent, training representation, attention cache, model parameter or feature schema. The official source tree remains unmodified. Forecaster checkpoint semantics advance to `tabicl_case_control_prior_v2_row_local_power`; the normal loader rejects legacy checkpoints for this revised experiment.

On the exact preserved failure context, the amended later-query error and shorter-batch error are both **zero for both assets**. Unperturbed prefix forecasts also remain exactly unchanged. This diagnostic reads context labels only as part of the already fitted cache and reads no assessment targets or accuracy metrics. It creates no additional context fit. Its immutable results are in `data/research/boundary_tabicl_20260908/row_local_diagnostic.json`.

Three focused regression tests cover the actual power-overflow mechanism, ordinary extrapolation, batch splitting, singleton equivalence, persistence, installation and fallback accounting. The repeated two-member synthetic forecaster check also passes: checkpoint forecasts reproduce exactly, later-query and shorter-batch errors are zero, and single-row numerical differences remain below 0.0000004. Those small single-row differences are compatible with changed floating-point matrix-operation shapes and satisfy the original registered tolerance.

The [amendment](boundary_tabicl_row_local_amendment_20260908.json) preserves all eight original procedure attempts and restarts the entire 24-procedure family in a distinct output directory after freezing updated hashes. Contexts, features, priors, dates, models, controls, all 876 assessment panels and causality tolerances remain fixed. Initial market forecasts are not reused. Published benchmark results and this correctness fix provide no evidence of improved market accuracy.
