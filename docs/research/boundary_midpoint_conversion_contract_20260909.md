# Trade-side conversion midpoint proxy

The training-only conversion diagnostics identified a 0.0001 USDT/TUSD minimum observed price spacing on May 29-June 1, 2023. More than 99.9% of adjacent opposite-aggressor trades within one second differed by that spacing on each date. This supports testing a fixed half-spacing adjustment, without asserting that a true executable quote was observed.

For an observed conversion trade with price r and aggressor sign q (+1 for an aggressive buy, -1 for a sell), use the midpoint proxy r - h q with h fixed at 0.00005 USDT/TUSD. The `raw_side` control uses h=0 and retains the same observed sign. The `midpoint_side` variant uses h=0.00005. The parameter is fixed from the earlier four training dates, never re-estimated from assessment outcomes or retuned per source day.

The transformed conversion retains the original publisher timestamp. It is available only strictly after that timestamp plus the declared 100 or 500 ms delay. Both the transformed rate and its side indicator use the original publication-age bound of 60 seconds. Missing or stale rates and signs are masked identically. Native-market returns, signed volumes, quantities, original decision clocks and source-availability masks remain exactly unchanged. Converted basis fields and the conversion log rate may change; they use the same original basis calculation and EWM missing-observation treatment.

The additional `conversion_last_side` field is included in both control and adjusted features. It must also be retained by each conversion-only model. Comparisons between raw-plus-side and midpoint-plus-side therefore test the representation given the same observed information. A comparison with the earlier raw-only model additionally changes the side information available to the learner and must be labeled accordingly.

This is a research feature, not a correction to an observed execution price. Half-spacing is an explicit model assumption with units of target quote per native quote. If the true spread changes, the midpoint proxy may become inaccurate. Lower observed FX increment variance alone does not demonstrate lower latent-price error, improved predictive accuracy or trading profits. A frozen matched predictive experiment is required before any promotion.

The June 1 training preflight produced four 80-column caches, including decision time, from BTC/TUSD and TUSD/USDT sources. All original raw feature values were reproduced exactly by the zero-adjustment control. Raw and adjusted variants share exact side, native-flow and availability values; truncated-source prefixes and Parquet persistence reproduce exactly. Full-window preparation applies the same fixed transforms on all fourteen exposed source dates, with one isolated source worker at a time and the original 3 GiB sampled RSS / 300 second daily limits. No target labels or predictive scores are read during feature preparation.

Synthetic checks cover aggressor-sign direction, one-ULP agreement with a decimal midpoint reference, unchanged clocks, exact zero-adjustment replay, strict release boundaries, missing/stale conversion masking, future-prefix invariance, unit scaling and invalid inputs. The full repository suite passed 717 tests; the minimal dependency setup passed 492 applicable tests with 6 optional tests and 68 optional modules skipped.
